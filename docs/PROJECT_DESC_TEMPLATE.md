# 项目描述模板（AI 优化）

> 总长≤300字。键名缩写：name=项目名 goal=核心目标 feat=功能 stack=技术栈 flow=数据流

```yaml
---
ver: 1
scope: repo
# 1) 项目名称 15字内
name: "[项目名]"

# 2) 核心目标 50字内
goal: "[一句话说明要解决的问题或达成的目标]"

# 3) 关键功能 每点20字内
feat:
  - "[功能1]"
  - "[功能2]"
  - "[功能3]"

# 4) 技术栈 仅关键组件
stack: "[组件1, 组件2, 组件3]"

# 5) 数据流 ASCII
flow: |
  [源] --> [处理] --> [输出]
```

---

## 填写说明

| 要素 | 上限 | 要求 |
|------|------|------|
| name | 15字 | 中文或英文全称/简称 |
| goal | 50字 | 主谓宾完整一句 |
| feat | 每点20字 | 动词开头，分点列出 |
| stack | 仅关键 | 语言/框架/存储/队列等，逗号分隔 |
| flow | ASCII | 箭头表示流向，可多行 |

---

## 示例（TrendRadar）

```yaml
---
ver: 1
scope: repo
name: "TrendRadar 舆情热点监控"

goal: "聚合多平台热点与RSS，按关键词筛选后推送并支持AI分析。"

feat:
  - "多平台热榜抓取与聚合"
  - "关键词/RSS筛选与推送"
  - "AI分析、翻译与MCP对话"

stack: "Python, SQLite, LiteLLM, 多通道Webhook"

flow: |
  平台API/RSS --> 抓取 --> SQLite
       --> 关键词过滤 --> 推送(企微/飞书/钉钉/邮件等)
       --> AI分析 --> 简报
  MCP <--> SQLite (查询/分析)
```

示例正文（不含frontmatter与代码块标记）约 280 字，符合 300 字上限。
